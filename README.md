# Projeto de Software 2026

Repositório do MVP desenvolvido na disciplina **Projeto de Software** (Cruzeiro do Sul Virtual), no formato de fábrica de software extensionista, com foco em gerar impacto social para uma comunidade parceira.

## Sobre o projeto

> 🚧 Projeto em fase inicial. A descrição do problema, da comunidade parceira e do MVP será detalhada nas próximas etapas.

## Objetivos

- Desenvolver um MVP que resolva uma necessidade real da comunidade parceira
- Aplicar práticas ágeis (Scrum) e de engenharia de software colaborativa
- Versionar todo o código com Git, seguindo boas práticas de commits, branches e pull requests
